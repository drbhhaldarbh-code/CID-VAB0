# منصة CID MadOut2 — نسخة تشغيلية

## التشغيل
1. ثبّت Node.js.
2. افتح مجلد المشروع.
3. شغّل: `npm install`
4. ثم: `npm start`
5. افتح: `http://localhost:3000`

## حسابات المعاينة
- المدير: `admin` / `ChangeMe123!`
- النائب: `deputy` / `Deputy123!`
- المارشال: `marshal` / `Marshal123!`
- الجنرال: `general` / `General123!`
- العضو: `member` / `Member123!`

## الصلاحيات
- المدير: إدارة الأعضاء والمطلوبين والمهام والقوانين + الأرشيف.
- النائب: إدارة الأعضاء والمطلوبين والمهام.
- المارشال: إدارة المطلوبين والمهام.
- الجنرال: إدارة المطلوبين والمهام.
- المشرف: إدارة المطلوبين والمهام.
- العضو: عرض الأقسام المسموحة فقط.

الأرشيف محمي من الخادم ولا يعتمد على إخفاء HTML فقط، والمدير وحده يملك صلاحية `/api/archive`.

قبل النشر العام غيّر كلمة مرور المدير وسر الجلسة، واستخدم HTTPS.


## التعديل الجديد
- لا توجد واجهة حذف للسجلات.
- طلبات DELETE على واجهات API مرفوضة للحفاظ على ثبات المعلومات.
- المعلومات الخاصة تسجل في سجل تدقيق، والمدير وحده يستطيع قراءة الأرشيف وسجل التدقيق.
- الصلاحيات تظل مرتبطة بالرتبة من جهة الخادم.


## الإصدار V3
- المدير والنائب: صلاحية الحذف.
- العضو والجنرال: إضافة معلومات فقط.
- المارشال: صلاحية إدارة الإعلانات.
- تمت إضافة رتبة كل عضو وصلاحياتها بشكل واضح داخل المنصة.
- تمت إضافة محادثات خاصة بين الأعضاء.
- تمت إضافة «إرسال ملاحظة للإدارة».
- الملاحظات تظهر للمدير فقط في لوحة الإدارة.
